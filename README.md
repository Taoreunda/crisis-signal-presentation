# 최종 발표 자료

대화 속 위기 신호 포착 모델 개발과 로컬·API 모델 비교 결과를 소개하는 11장짜리 HTML 발표입니다.

## 공유 URL

- 발표: <https://taoreunda.github.io/crisis-signal-presentation/>
- 공개 저장소: <https://github.com/Taoreunda/crisis-signal-presentation>
- GitHub Pages는 공개 저장소의 `main` 루트에서 배포합니다.
- 링크 미리보기는 `index.html`의 Open Graph·Twitter 메타 정보와 `assets/share-preview.png`를 사용합니다. 썸네일은 발표 1장의 정지 화면입니다.
- 발표 HTML·이미지·브라우저 실행 파일과 발표용 집계 수치만 배포 대상으로 둡니다. 상담 원본·건별 예측·가중치·전체 실행 기록은 포함하지 않습니다.

2026-10-26 갱신: 총 11장, 로컬 10종·API 3종 비교와 혼동행렬을 포함합니다.

발표 수정은 이 폴더에서 합니다. 수정 후 발표 파일만 배포 저장소에 반영해 push하면 Pages가 갱신됩니다. 로컬 수정만으로 공유 URL이 바뀌지는 않습니다. 이 프로젝트 전체를 공개 저장소에 push하지 않습니다.

## 실행

이 README가 있는 발표 폴더에서:

```bash
python3 -m http.server 8766 --bind 127.0.0.1
```

브라우저에서 <http://127.0.0.1:8766/>을 엽니다. 서버가 이미 실행 중이면 주소만 열면 됩니다.
파일을 더블클릭하는 대신 로컬 서버로 실행합니다. 폴더 전체를 복사하면 다른 컴퓨터에서도 실행할 수 있습니다.
모델 실행, GPU, npm 설치는 필요하지 않습니다.

## 조작

- **발표 시작** 또는 **P**: 현재 탭을 전체 화면으로 전환합니다.
- **발표 종료**, **Esc**: 일반 화면으로 돌아옵니다. **P**, **F**로도 전환할 수 있습니다.
- **← / →** 또는 하단 화살표: 이전 / 다음 장으로 이동합니다.
- 페이지 번호와 이동 버튼은 발표 중에도 표시합니다. 새 청중 탭은 열지 않습니다.
- 1장만 반복 재생합니다. 2~5장은 한 번 재생 후 유지하며 다시 진입하면 재시작합니다.
- 6~10장은 결과 표와 평가 조건을 표시합니다. 결과 표의 열 제목을 누르면 **내림차순 → 오름차순 → 기본 순서(F1 순서)**로 전환됩니다. 다른 열은 내림차순부터 시작하며 동점은 기본 순서를 유지합니다. 모델명 열도 이름으로 정렬할 수 있고 Enter·Space로도 조작할 수 있습니다. 강조 행은 항상 F1 1위 모델을 가리킵니다.

## 파일

```text
presentation/
├── index.html                 # 발표 실행·페이지 이동·전체 화면
├── slides.html                # 최종 11장과 애니메이션·발표자 노트
├── README.md                  # 실행 방법과 출처
├── tools/prepare.py           # 집계 표·노트 동기화 및 공개 파일 내보내기
└── assets/
    ├── aihub-child-counseling.png
    ├── aihub-child-counseling.source.json
    ├── local-model-results.source.json # 결과 집계값·분모·출처 해시
    ├── share-preview.png          # 공유 링크 미리보기
    └── vendor/
        ├── gsap.min.js
        ├── hyperframes-player.global.js
        ├── hyperframes-slideshow.global.js
        └── HYPERFRAMES-LICENSE
```

`index.html`로 발표를 엽니다. `slides.html`은 플레이어가 불러오는 본문입니다.
슬라이드 순서·발표자 노트는 `slides.html`의 `application/hyperframes-slideshow+json`에서만 수정합니다. HyperFrames의 정적 메타데이터 요구 때문에 `index.html`에도 같은 내용이 필요하며 `tools/prepare.py`가 복사합니다. 결과 표는 출처 JSON에서 생성하고 정렬 로직은 모든 표가 함께 사용합니다.
시안·중복 이미지·예제 컴포넌트·제작 도구 설정·로컬 제작 기록은 정리했습니다.
11장의 혼동행렬은 예측 행·라벨링 열을 고정한 정지 표이며 정렬 대상이 아닙니다. 셀에는 건수·라벨링 열 기준 비율만 표시하며 셀 설명·원본 총건수·선택 조건 안내는 발표자 노트에 둡니다.

## 내용과 출처

1. 대화 속 위기 신호 포착 모델 개발
2. System One: 추론형 LLM(GPT·Qwen)과 System One(Nimble·Jev)의 흐름 비교
3. System One 모델의 판단 과정: 0% → 94% → `{"risk": 0.94}`
4. 상담 데이터: 공식 전체 3,596건
5. 모델 성능 확인 및 LoRA 파인튜닝: 아동·청소년 공개 자료 → Qwen·Nimble·Laya·GPT·Jev 평가·비교 → 성능 부족 시 LoRA 파인튜닝. 성인 증강 데이터는 별도 가지에서 LoRA 학습으로 직접 연결하며 결과 모델 상자는 두지 않습니다.
6. 비교 모델과 실행 조건: 로컬 모델 10종을 가로 5개 × 세로 2줄 카드로 표시하고 아래에 데이터 3,236건·로컬·Jev 3회 및 GPT 1회·평가 항목·RTX6000 48GB를 배치합니다.
7. 원본 라벨별 건수: 자살욕구·자해욕구의 있음/없음 표와 종합 위기 5단계별 건수 표를 한 장에 나란히 표시합니다. 제외·실패 처리는 작은 보조 설명으로 둡니다.
8. 자살 판정: 13종의 정확도·양성 정밀도·양성 재현율·양성 F1, F1 순서
9. 자해 판정: 같은 지표, F1 순서
10. 종합 위기 5단계: 정확도·macro 정밀도·macro 재현율·macro F1
11. 상위 모델의 혼동행렬: 자살 Qwen3.8 27B와 자해 Clef Flash 9B의 2회차를 나란히 표시. 건수와 원본 라벨별 비율, 놓침 테두리를 표시합니다.

6~10장에는 집계일·제외 모델 등의 하단 각주를 표시하지 않습니다. 6장은 API 모델 3종을 작은 글자로 추가하고, 8~10장은 GPT 2종에만 별표와 1회 결과 주석을 표시합니다. 결과 표 아래의 중복 수치 요약과 해석 문구도 표시하지 않습니다. 평가 데이터와 처리 기준은 7장에 모았습니다. 자살·자해 표에는 있음·없음만 표시하며 해당 없음은 평가에서 제외했다고 작게 설명합니다. 종합 위기 표는 정상군 665건·관찰필요 634건·상담필요 621건·학대의심 644건·응급 672건을 표시합니다. 조건과 출처는 발표자 노트와 아래 기록에서 관리합니다. 6장 실행 환경은 요청한 간략 표기 `RTX6000 48GB`를 사용하며 원 실행 기록의 정확한 장비명은 RTX A6000 48GB입니다.

### 결과 수치의 출처와 해석

6~11장은 `outputs/model_comparison/2026-10-25_all_models_unified_review_145400_410756/metrics.json`의 집계값을 사용합니다. 이는 기존 10월 23일 실행을 모은 결과이며 추가 학습 결과가 아닙니다. `assets/local-model-results.source.json`에 발표용 집계값, 회차별 평가 분모·실패·시간, 원본 SHA-256을 보존합니다. HTML은 수치를 정적으로 표시하며 예측이나 성능 계산을 다시 구현하지 않습니다. 출처 JSON이나 본문 노트를 수정한 뒤 `python3 tools/prepare.py`로 결과 표·진입 페이지 노트·캐시 버전을 함께 갱신합니다.

자살은 3,204건(양성 351건), 자해는 3,227건(양성 127건)이 평가 대상입니다. 원본의 해당 없음은 제외하며 출력 실패는 성공한 응답의 성능 분모에서 제외합니다. 화면은 모델명·정확도·정밀도·재현율·F1로 구성하며 지표는 로컬 10종·Jev의 3회 평균과 GPT 2종의 1회차 값(%)입니다. 자살·자해의 열 이름은 F1, 5단계는 Macro F1입니다. SD 열은 표시하지 않으며 표본 표준편차는 원본 집계에 보존합니다. 5단계의 macro 정밀도·재현율·F1은 각각 클래스별 해당 지표의 동일 가중 평균입니다. 시간·실패 집계는 출처 JSON에 보존하며 발표 화면에는 시간 표를 두지 않습니다. 전체 13종을 F1 내림차순으로 표시합니다. Jev 1.13.0은 3회 평균, GPT-5.6 Luna·Terra는 완료된 1회차 결과이며 미완료 회차는 포함하지 않습니다. 추가한 API 결과의 사용 회차는 모두 입력 3,236건, 성공 3,236건, 실패 0건입니다. API 지표와 회차 기록은 출처 JSON의 `api_models`에 보존합니다. 11장 혼동행렬은 로컬 모델 중 선택한 기존 결과를 유지합니다.

이 결과는 아동·청소년 상담의 기존 라벨 재현을 살펴본 탐색 비교입니다. 원본의 자살·자해 욕구 라벨과 위험을 묻는 프롬프트의 차이도 남아 있습니다. 성인 면담이나 타해 감지 성능을 검증한 결과로 사용하지 않습니다. 같은 자료의 3회 반복은 독립적인 평가 세트 3개가 아닙니다. 조건·정의·회차별 놓침과 오탐은 발표자 노트에도 기록했습니다.

94%는 설명용 가상 모델 점수이며 실제 실행 결과·정답률·임상적 발생 확률이 아닙니다.
LoRA 격자 애니메이션은 개념 설명이며 실제 학습 가중치나 로그가 아닙니다.
공식 데이터 규모, 공개 벤치마크의 조건과 한계, 성인 평가 계획은 발표자 노트에 보존했습니다. 전체 상담을 이용한 13종 탐색 비교는 수행했고 입력·요청·응답을 보존합니다. 학습용 추출·라벨링·분할·성인 증강은 별도 결정 전입니다. 상담 원문과 전체 실행 기록은 이 공개 발표 저장소에 포함하지 않습니다. 내부 연구 저장소의 `experiments/model_comparison/README.md`에서 관리합니다.

### 혼동행렬 출처

11장은 항목별 로컬 모델 3회 평균 F1 1위의 공통 2회차를 사용합니다. 두 모델 모두 해당 회차 실패 0건입니다. 라벨링 열 기준 비율과 건수는 `assets/local-model-results.source.json`의 `confusion_matrices`에 보존합니다. 앞의 비교표는 로컬·Jev 3회 평균과 GPT 1회차, 혼동행렬은 선택한 로컬 모델의 단일 회차로 구분합니다. 원본 라벨 재현 결과이며 임상적 진단 결과가 아닙니다.

혼동행렬은 비율(80px)을 주 정보로, 건수(40px)를 보조 정보로 표시합니다. 축 제목은 회색 띠, 있음·없음 머리글은 짙은 배경과 구분선으로 묶으며 행은 예측, 열은 라벨링입니다.

## 수정·검증·배포

발표 폴더에서 다음을 실행합니다. Python 표준 라이브러리만 사용합니다.

```bash
python3 tools/prepare.py                   # 표·노트·캐시 버전 동기화
python3 tools/prepare.py --check           # 불일치가 있으면 실패
python3 tools/prepare.py --export /path/to/crisis-signal-presentation
```

내보내기는 `tools/prepare.py`의 명시적인 공개 파일 목록만 복사합니다. 연구 데이터·예측 원문·모델 가중치·로컬 제작 기록은 복사하지 않습니다. 기존 배포 저장소에서 변경 목록을 검토하고 커밋·push하면 Pages가 갱신됩니다. 복사 대상에 이미 있는 다른 파일은 자동 삭제하지 않습니다. 결과 표의 원본은 `assets/local-model-results.source.json`, 노트와 화면 디자인의 원본은 `slides.html`입니다. 생성된 표의 숫자나 `index.html`의 노트를 따로 수정하지 않습니다.
